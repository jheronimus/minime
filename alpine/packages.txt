# NextUI Alpine base package selection
#
# One package per line; '#' starts a comment. Installed into the Alpine rootfs
# by the image build after the local package repo is staged.
#
# SHARED BY BOTH BOARDS. Minime keeps a per-board world-<board> overlay, but
# both of theirs are empty for H700 and RK3566: the only board deltas are
# in-kernel (DMC devfreq, PSCI idle on RK3566) and need no userspace packages.
# We have the same two boards, so we have the same single list. Revisit only if
# a board needs a package the other does not.
#
# Derived from Minime's packages/components/alpine/configs/world-common.
# Differences are called out inline as DROP / ADD / RENAME.
#
# Notes carried over from upstream, because they are load-bearing:
#   - musl replaces glibc. gcompat is intentionally omitted; anything that
#     hard-depends on glibc does not belong on this list.
#   - No libmali / mali-kbase. Mesa Panfrost provides GLES via DRM/GBM/KMS on
#     both SoCs (Mali-G31 on H700, Mali-G52 on RK3566).

# dropbear: SSH server, enabled by default via the boot runlevel. Provides an
# encrypted remote shell alongside telnet.
dropbear

# --- DNS / mDNS ------------------------------------------------------------
# openresolv: iwd hands the DHCP DNS servers to it (NameResolvingService=resolvconf).
# mdnsd announces the device as <hostname>.local so telnet/ssh/ftp are reachable
# by name. It is built from alpine/aports/mdnsd and is listed under Local
# packages at the bottom of this file, because build.sh builds it from source.
openresolv

# libstdc++: C++ runtime for cores that need it.
libstdc++
# libretro-gambatte: Game Boy / Game Boy Color core for test runner.
libretro-gambatte

# --- Local packages (built from alpine/aports/*) ---------------------------
# These MUST have a matching alpine/aports/<name>/APKBUILD. build.sh asserts
# this before entering the chroot, so a typo here fails immediately with a
# useful message instead of "unable to select packages" from deep inside apk.
#
# Deliberately NOT listed, though Minime's world-common does:
#   bootsplash  Minime's own C daemon (src/bootsplash). Minime ships no
#               LICENSE file, so we do not vendor their source. Both consumers
#               are guarded with `if [ -x /usr/bin/bootsplash ]`
#               (init.d/bootsplash and initramfs-init.sh), so the image boots
#               and runs without it -- just with no early splash.
#   remote      Minime's own C tool (src/remote), for remote screenshot and
#               input injection. Diagnostic only; nothing in the overlay
#               invokes it.
# Both are additive: build the aports and re-add the line when you want them.
fatresize
mdnsd
