# Boot Chain, Initramfs & Bootsplash

## Problem
Embedded gaming handhelds require near-instant boot times, reliable rootfs mounting, graphical splash feedback during early boot, and unified service management across distributions.

## Solution
U-Boot loads `boot.scr`, which initializes the kernel and minimal initramfs. The initramfs mounts the FAT32 userdata partition, mounts the compressed read-only `system.erofs` rootfs, and executes `switch_root`. OpenRC manages service lifecycles across both Alpine and Buildroot, starting `bootsplash` immediately before background daemons and the UI launcher.
