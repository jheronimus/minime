# UI Architecture & Launcher Ports

## Problem
Launchers (MinUI, Allium, muOS) have varying architectures, filesystem requirements, and asset hierarchies that risk polluting the base firmware with distro-specific workarounds.

## Solution
Minime treats launchers as decoupled consumers running as non-root users. Launchers read hardware specifications strictly from `/mnt/sdcard/.minime/traits` and store configuration on `/mnt/sdcard/`. Minime-specific platform code is contained strictly within the platform port directory of each launcher repository.

## Examples
- MinUI platform port: `packages/ui/minui/workspace/minime/`
- Allium platform port: `packages/ui/allium/crates/common/src/platform/minime/`
